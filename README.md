# DropoutGuard
## Student Dropout Prediction and Early Warning System

### Project Overview
DropoutGuard is a machine learning-based system that predicts
student outcomes and estimates dropout risk.

### Features
- Student Dropout Prediction
- Random Forest Machine Learning Model
- SHAP Explainable AI
- Student Dashboard
- Faculty Risk Monitoring
- Intervention Tracking
- Admin Dashboard
- Reports and Analytics

### Technologies Used
- Python
- FastAPI
- Scikit-learn
- SHAP
- Pandas and NumPy
- SQLite
- HTML, CSS and JavaScript
- Chart.js

### Dataset
UCI Predict Students' Dropout and Academic Success.

### Backend Setup

python -m uvicorn main:app --reload
